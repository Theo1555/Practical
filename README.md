# WhatsApp Desktop Knowledge Base

A practice technical-writing project that provides practical, step-by-step documentation for using WhatsApp on a desktop computer.

## About the Project

This knowledge base is designed to help new and existing WhatsApp users understand common desktop features and complete everyday tasks with clear, easy-to-follow instructions.

The documentation focuses on task-based guidance, practical workflows, screenshots, and user-friendly explanations.

> **Disclaimer:** This is a practice project created for learning and portfolio purposes. It is not affiliated with, endorsed by, or officially provided by WhatsApp or Meta. Interface elements and available features may vary depending on the WhatsApp version and platform.

## Documentation

The complete documentation is organized into individual guides:

* [**Overview**](Overview.md) — Introduction to the knowledge base and its documentation structure.
* [**Getting Started**](getting-started.md) — Initial setup and basic requirements.
* [**Messaging**](messaging.md) — Sending, replying to, forwarding, and searching for messages.
* [**Calls**](calls.md) — Making and managing voice and video calls.
* [**Group Calls**](Group-calls.md) — Starting group calls and managing participants.
* [**Sharing Photos and Videos**](sharing-photos-and-videos.md) — Sending, downloading, and managing media.
* [**WhatsApp Status**](whatsapp-status.md) — Creating, viewing, and managing status updates.
* [**Contacts**](contacts.md) — Adding, searching, viewing, and blocking contacts.
* [**Groups**](groups.md) — Creating and managing WhatsApp groups.
* [**Privacy & Security**](privacy--security.md) — Managing privacy and security settings.
* [**Troubleshooting**](troubleshooting.md) — Guidance for resolving common issues.

## Documentation Approach

This project demonstrates the use of:

* Task-based documentation
* Step-by-step instructions
* Clear information architecture
* Screenshot-based guidance
* User-focused technical writing
* Accessibility-conscious documentation

## Intended Audience

The knowledge base is intended for:

* New WhatsApp desktop users
* Users looking for guidance on specific features
* Anyone who prefers step-by-step instructions for completing common tasks

## Project Purpose

This project was created to practice and demonstrate technical-writing skills, particularly in creating structured user documentation for a software product.
